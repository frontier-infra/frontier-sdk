## What is complete

The Foundation now has a reusable, package-bound Harness Kit boundary rather
than only an in-repository demonstration. It includes:

- a deterministic contract, verifier, proposal, capability, adapter, receipt,
  halt, budget, quarantine, and durable JSONL lifecycle;
- fail-closed effect authority bound to the ratified verifier and an explicit
  effect allowlist;
- semantic replay validation that recomputes contract and proposal hashes and
  rejects forged verification evidence;
- opaque, one-time, scoped, expiring effect capabilities;
- public declarations for all six TypeScript packages, checked from packed
  tarballs by a strict external consumer;
- a neutral second consumer that imports only the public Harness Kit package and
  proves one exact local effect plus tamper, replay, expiry, policy, and halt
  failures;
- one non-publishing RC gate covering Node, Python, TypeScript, package chaos,
  generated snapshots, the second consumer, and reproducible package assembly;
- a clean-source requirement for RC artifacts and a manifest-derived publication
  list. Only packages explicitly enabled in the manifest can enter that list.

This is package/Foundation completion. It is not a claim that a production
deployment, external connector, or commercial product is complete.

## Package decisions

- Keep `@frontier-infra/governance-react`; `@frontier-infra/react` would imply a
  generic React runtime that this package is not.
- Keep one small, dependency-injected `@frontier-infra/adapters` package for this
  RC. Split future adapters only when heavyweight dependencies, licensing, or
  credential-isolation boundaries justify independent custody.
- `frontier-foundation-0.1.0-rc.1` is the assembly identifier. Contained package
  versions remain protocol `0.1.0`, audit `0.1.2`, and the four incubating
  packages at `0.1.0`.
- Protocol and audit are the only manifest-enabled publication candidates. No
  package was published by this work.
- `create-frontier-app` is reproducible from the RC tarball set. Its normal
  registry install cannot succeed until its currently unpublished Harness and
  governance dependencies are published; that is a release-custody decision,
  not something this non-published RC disguises.
