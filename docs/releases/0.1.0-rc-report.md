## Rebuild instructions

Use Node `22.23.1`, npm `10.9.8`, and this sibling layout:

```text
<root>/
├── frontier-infra/
│   ├── frontier-sdk/       # checkout 8a773e6
│   ├── plugins/            # checkout 04db450
│   ├── the-machine/
│   ├── agentcontrolplane/
│   └── avl/                # build its official CLI
└── journeyman/             # checkout 32b0283
```

Then run:

```bash
cd <root>/frontier-infra/frontier-sdk
npm ci --ignore-scripts
FRONTIER_AVL_CLI=<root>/frontier-infra/avl/dist/cli.js npm run rc:verify

cd <root>/journeyman/product
npm ci
npm run verify
```

`npm run rc:verify` executes Node, Python, strict TypeScript consumer, simulated
chaos, audit snapshot, plugin consumer snapshot, and reproducible package gates.
`npm run rc:pack` alone rebuilds the ignored artifact directory without publishing.
